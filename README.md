# catalan

Програмата показва реда на Каталан като формален степенен ред над три пръстена: ℤ, ℚ и 𝔽₂.
Формален степенен ред е безкрайна редица от коефициенти с операции като при полиноми.
Програмата проверява тъждеството `1 - α + t·α² = 0` и решава квадратно уравнение в ℚ без корен квадратен.

## Структура

- `fps/` съдържа интерфейса `Ring`, типа `FPS` и генератора `Catalan`.
- `rings/` съдържа пръстените `BigInt` (ℤ), `BigRat` (ℚ) и `GF2Ring` (𝔽₂).
- `quadratic/` съдържа `Solve` и `Residual` за уравнението `c0 - c1*x + c2*x² = 0`.
- `cmd/catalan/` съдържа изпълнимата програма.

## Компилиране и стартиране

Проектът изисква Go 1.21 или по-нов.

За да инсталирате програмата без клониране, изпълнете:

```bash
go install github.com/rosenk/catalan/cmd/catalan@latest
```

За да компилирате от клонирано хранилище, изпълнете:

```bash
make build      # създава bin/catalan
make run        # компилира и стартира програмата
make test       # изпълнява тестовете
```

Програмата приема тези флагове:

- `-a`, `-b`, `-c` задават коефициентите на `a*x² + b*x + c = 0`. Стойността може да е цяло число, дроб (`7/3`) или десетично число.
- `-digits` задава броя значещи цифри на корените (по подразбиране 30).
- `-n` задава броя коефициенти за проверка на тъждеството (по подразбиране 20).

Ако не зададете `-a`, `-b` или `-c`, програмата показва демонстрацията и решава `x² - 5x + 1 = 0`.

Например за уравнението `x² + 5x - 7 = 0` изпълнете:

```bash
./bin/catalan -a 1 -b 5 -c -7
```

Програмата намира двата реални корена. Ако уравнението няма реални корени, тя съобщава това и завършва с код 1.

## Как програмата решава уравнението

Вътре програмата използва формата `c0 - c1*x + c2*x² = 0`, където `c0 = c`, `c1 = -b` и `c2 = a`.
Редът на Каталан дава корена на `c0 - c1*x + c2*x² = 0`, който е най-близо до 0: `x = (c0/c1) * α(t)`, където `t = c0*c2 / c1²`.

1. Програмата пресмята дискриминантата `D = c1² - 4*c0*c2 = c1²(1 - 4t)`. Ако `D < 0`, уравнението няма реални корени. Ако `D = 0`, коренът е `c1 / (2*c2)`.
2. Програмата избира начална точка `s = v ± h`, където `v = c1 / (2*c2)` е средата между корените. Знакът е знакът на `v`, затова `s` е до корена, който е по-далеч от 0.
3. Числото `h` е `2^m`, `(3/2)·2^m` или `2^(m+1)`, където `m` е половината от двоичния порядък на `D / (4*c2²)`. Програмата взима първия кандидат, при който `s` е извън корените. Тя не пресмята корен квадратен, а брои битове и проверява един знак. В тази точка `0 <= t < 5/36`.
4. На всяка стъпка програмата замества `x = y + s`, сумира 8 члена от реда на Каталан за `y` и премества `s` в `s + y`. Стъпка с M члена е метод от ред M + 1, затова броят верни цифри расте около 9 пъти на стъпка. Числото `t` остава `>= 0`, защото `p(s + y) = p(s)·E_M(t)`, а `E_M(t) = 1 - P_M(t) + t·P_M(t)²` има само положителни коефициенти.
5. Програмата спира, когато стъпката `y` е под исканата точност. Вторият корен идва от формулата на Виет `x1 * x2 = c0 / c2`. Тя пази относителната точност и на малкия по модул корен.

Функцията `Solve` приема и `t < 0`. Тогава тя прилага замяната на Мьобиус `u = -t / (1 - 4t)`, сумира `β = α(u)` и връща `α = β / (1 - 4t + 2tβ)`. `AutoSolve` не стига до този случай.

## Ограничения

Функцията `Solve` изисква `c1 != 0` и `t < 1/4`. Функцията `AutoSolve` покрива и случая `c1 = 0`, защото началната точка винаги дава `c1 != 0`.
При `D = 0` редът е на границата `t = 1/4`, затова програмата връща двойния корен директно.
Програмата смята точно в ℚ. При 2000 цифри тя работи около 1 секунда, а при 10 000 цифри около 15 секунди.
Редът от `Catalan` пази кеш и не е безопасен при едновременна употреба от няколко goroutine.
